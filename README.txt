BLUEZ INFOMATIC SOLUTIONS — WEBSITE PROJECT
============================================

HOW TO RUN
1. Extract bluez_infomatic_solutions.zip.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or install the VS Code extension "Live Server".
4. Right-click index.html and choose "Open with Live Server".

PAGES
- index.html   Home page
- about.html   Company overview and founder section
- services.html  Application, website, BPO and Java services
- careers.html  Vacancy cards and application form
- contact.html  Contact details and enquiry form

CUSTOMISATION NOTES
- Edit colours, layouts and animations in style.css.
- Edit page text in the corresponding HTML files.
- Replace the Unsplash image URLs with your own company/team/project photographs.
- The logo is assets/logo.svg and can be edited as an SVG.
- The forms use mailto links: they open the visitor's default email application.
  They do not store submissions in a database. For production use, connect a
  secure backend or form service and add spam protection.
- The 4.5/5 rating is displayed as requested. Publish it only if it reflects
  a genuine, verifiable rating and add its review source.
- Founder wording is a general profile draft. Confirm factual details with
  the founder before publishing.
- Vacancy titles are sample listings. Update them to reflect active openings.

IMAGES & FONTS
The site uses remote images from images.unsplash.com and Google Fonts.
An internet connection is needed to load those assets. Download licensed
company-owned images for a fully self-contained production website.
